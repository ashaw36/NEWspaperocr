## 📋 启动步骤

### 方法一：使用快速启动脚本（推荐）

1. **双击运行脚本**：
   ```
   D:\古报纸OCR\backend\start_demo.bat
   ```

2. **等待服务启动**（约3-5秒）

3. **打开浏览器访问**：
   ```
   http://127.0.0.1:5000/demo
   ```

### 方法二：手动启动

1. **打开命令行**，进入后端目录：
   ```bash
   cd D:\古报纸OCR\backend
   ```

2. **停止旧服务**（如果有）：
   ```bash
   # 查找占用5000端口的进程
   netstat -ano | findstr :5000
   
   # 停止进程（替换 PID 为实际的进程ID）
   taskkill /F /PID <进程ID>
   ```

3. **启动新服务**：
   ```bash
   python app.py
   ```

4. **打开浏览器**访问演示界面

## 🐛 常见问题

### Q: 打不开演示页面？
**A**: 检查服务是否正常启动：
```bash
curl http://127.0.0.1:5000/api/health
```
应该返回 `{"status": "healthy", ...}`

### Q: 处理时间很长？
**A**: 正常情况下：
- 简单报纸：30-60秒
- 复杂报纸：60-120秒
- 首次使用会下载模型（可能需要5-10分钟）

### Q: 识别准确率不高？
**A**: 可能原因：
- 图像质量不佳（模糊、破损）
- 字体太小或太特殊
- 版面过于复杂

## 💡 技术架构

### 后端技术
- **Flask** - Web 框架
- **PaddleOCR PP-OCRv5** - OCR 引擎（繁体字+竖排优化）
- **DeepSeek API** - AI 增强（版面分析、文章聚合、内容总结）

### 前端技术
- **原生 HTML/CSS/JS** - 无框架依赖
- **现代 CSS** - Grid + Flexbox + 自定义属性
- **Fetch API** - RESTful 通信

### 核心算法
1. **图像预处理** - 去噪、二值化、倾斜校正
2. **版面分析** - AI 辅助的区域检测
3. **OCR 识别** - PaddleOCR 批量处理
4. **文章聚合** - 基于空间关系和 AI 判断
5. **质量验证** - 多维度自动检查
6. **文档生成** - 结构化输出
