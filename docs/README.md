## 📖 文档贡献

发现文档问题或想要改进文档?

1. 查看现有的 [文档Issue](https://github.com/ashaw36/NEWspaperocr/issues?q=label%3Adocumentation)
2. 创建新的 Issue 报告问题
3. 提交 Pull Request 改进文档

文档也是项目的重要组成部分,我们欢迎:

- 修正错别字和语法错误
- 补充遗漏的内容
- 改进表达和组织
- 添加示例和图表
- 翻译成其他语言
