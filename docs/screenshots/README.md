## 📐 截图规范

### 尺寸建议

- **全屏截图**: 1920x1080 或更高
- **局部截图**: 保持16:9比例
- **移动端截图**: 375x667 (iPhone) 或 360x640 (Android)

### 格式要求

- **格式**: PNG (推荐) 或 JPG
- **大小**: 单个文件不超过 2MB
- **质量**: 清晰可读,避免模糊

### 内容要求

- 使用示例数据,避免敏感信息
- 保持界面整洁
- 突出关键功能
- 必要时添加标注或说明

## 🎨 美化建议

### 添加标注

使用工具添加箭头、文字标注等:
- Windows: Snipping Tool, Paint 3D
- Mac: Preview, Skitch
- 跨平台: GIMP, Inkscape

### 边框阴影

为截图添加边框或阴影增强视觉效果:
```css
box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
border: 1px solid #e5e7eb;
border-radius: 8px;
```
